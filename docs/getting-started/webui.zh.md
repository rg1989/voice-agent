# WebUI

WebUI 是浏览器里的对话客户端。Gateway 在自己的源上静态托管它——不需要单独
部署前端服务。

## 打开方式

Gateway 运行中，在另一个终端执行：

```bash
qwenaudio webui
```

命令会打印页面地址（默认 `http://127.0.0.1:3101`）并用默认浏览器打开。
首次使用时浏览器会请求麦克风权限，允许后才能语音对话。

选项：

| 选项 | 含义 |
| --- | --- |
| `--url URL` | 连接其他地址的 Gateway（默认 `http://127.0.0.1:3101`） |
| `--session ID` | 复用指定的语音会话 |
| `--no-open` | 只打印地址，不打开浏览器 |

## 能做什么

- **全双工语音**——自然说话、随时打断，实时转写同步显示。
- **文本与附件**——输入文字、添加图片或文件；普通附件可交后台处理，不要求语音模型直接看图。
- **任务视图**——跟随派发给后台 Agent 的后台任务，包括进度与最终结果。

普通附件与实时视觉采集的区别见[对话与附件](../guides/conversation.zh.md)。
顶部“资料库”入口用于[导入本机文档](../guides/knowledge.zh.md)，不是聊天附件上传。

## 顶部控件

浏览器版 WebUI 的顶部栏有三个控件，桌面版的对话窗口不显示它们。

### 工作目录切换

目录标签显示后台 Agent 工作的文件夹名，鼠标悬停可看到完整路径。未设置文件夹时显示 **默认暂存目录**。

点击标签打开目录选择器：

- 输入路径后点 **前往**，或点击子目录进入。`~` 表示主目录。
- 点 **← 返回上一级** 回到上一级目录。
- 点 **在这里工作** 使用当前打开的文件夹。

Gateway 列出的是它所在机器上的文件夹。选择器不显示以 `.` 开头的文件夹，最多列出 500 个子目录。切换文件夹会重启 Gateway（见[设置面板](#设置面板)），Gateway 恢复后页面自动刷新。

工作目录切换只能在运行 Gateway 的电脑上使用，已配对的手机或其他远程设备无法使用。

### 会话历史

点时钟图标（**会话历史**）打开会话列表。列表来自 Gateway 的 Session Journal，只列出至少有一条消息的会话，最新的排在最前。每行显示你说的第一句话、最后一条消息的时间和消息数，屏幕上的会话标有 **当前**。

- 点击某一行切换到该会话。
- 删除会话：先点垃圾桶图标，再点 **确认删除**。Gateway 会从磁盘删除该会话的日志，删除后无法恢复。
- 删除的是屏幕上的会话时，WebUI 会新建一个会话。

按 Esc 或点击列表外部可关闭列表。

### 花费显示

花费显示今天语音模型用量的估算费用（美元），以及免费额度剩余比例的估算值。鼠标悬停可查看明细：

| 提示行 | 含义 |
| --- | --- |
| **这一场：… tokens，约 …** | Gateway 启动以来的 token 数，Gateway 重启后从 0 开始计。 |
| **今天：… tokens，约 …** | 当天（按 UTC 日期）的 token 数和费用。 |
| **免费额度剩余约 …** | 每个模型 1,000,000 token 的免费额度，减去 Gateway 为该模型记下的 token 数。 |

语音服务商在每次回复结束时报告 token 用量。Gateway 按内置价目表为当前配置的模型计价，文本和音频、输入和输出分别计价。计数保存在 Gateway 状态目录的 `usage.json` 中，最多保留 90 天。试听音色也会计入。

所有数字都是估算，不是账单：价目表随应用发布，Gateway 只看得到自己产生的用量，服务商也没有查询免费额度余额的接口。只有服务商因免费额度用完而拒绝请求后，才会显示 **额度已用完**。价目表里没有当前模型时，不显示花费。数据每 10 秒刷新一次。

## 设置面板

点齿轮图标（**设置**）打开面板。大多数设置保存在配置目录（默认 `~/.config/qwaudio/`）的 `config.env` 中，人设文本单独保存为文件。大脑、电脑控制、音色的选项和唤醒词名称由 Gateway 提供，中文界面中也显示为英文。

有些改动立即生效，其余改动会重启 Gateway，正在进行的任务会中断：

| 立即生效 | 重启 Gateway |
| --- | --- |
| 音色、机械音效、人设、聆听方式、媒体播放 | 大脑、电脑控制、工作目录、断句、隐私 |

重启期间面板显示 **正在重启 Gateway，稍后自动刷新…**，Gateway 恢复后页面自动刷新。45 秒后仍未恢复时，面板显示 **重启超时，请手动刷新页面**。

在已配对的手机或其他远程设备上，只能修改音色、机械音效、人设和聆听方式。其他设置（包括媒体播放）和目录选择器只能在运行 Gateway 的电脑上使用。

### 大脑

选择由哪个 Agent 做实际工作。各自沿用自己的模型和登录。

| 选项 | 说明 |
| --- | --- |
| **Claude Code** | 使用现有的 `~/.claude` 登录。 |
| **Codex** | 使用现有的 Codex 登录。 |
| **Oh My Pi** | 使用你在 Oh My Pi（`~/.omp`）中设置的服务商和模型，例如 Z.AI coding plan 订阅。 |
| **No agent** | 只进行语音对话。 |

只有 Gateway 找到 `omp` 命令时，面板才显示 **Oh My Pi**。Gateway 按顺序查找 `OMP_BIN`、`~/.bun/bin/omp`、`/usr/local/bin/omp` 和 `/opt/homebrew/bin/omp`。

### 人设

每个音色都有自己的角色，语音模型和大脑都按所选音色的角色说话。文本框显示的是所选音色的角色。

- 每个角色是配置目录中的一个文件：`personas/<Voice>.md`。
- 默认角色来自仓库中的 `config/frontend-agent/personas/`。只在文件不存在时复制默认文件，所以更新后你的修改仍然保留。
- **保存人设** 会写入该文件。内容不能为空，最多 4000 个字符。
- 保存后从下一次回答开始生效，Gateway 会把新的指令发给已打开的语音会话。
- 如果前台 profile 或 `QWEN_AUDIO_AGENT_ASSISTANT_PROFILE_PATH` 指定了助手 profile，文本框编辑的是那个文件，所有音色共用。
- 没有角色文件的音色使用配置目录中的 `ASSISTANT.md`，直到你保存为止。
- 选择另一个音色时，文本框中未保存的内容会被丢弃。

### 聆听方式

- **一直在听**（默认）：麦克风听到的声音都会发给语音模型。
- **唤醒词**：听到唤醒词之后才发给语音模型。

选择 **唤醒词** 后，面板还会显示：

- 唤醒词：**Hey Jarvis**（默认，标有 **推荐**）、**Hey Lisa**、**Hey Megan**、**Hey Mycroft** 或 **GLaDOS**。
- **回答后继续听多久**：0 到 10 秒，按 1 秒调节，默认 5 秒。

详见[唤醒词聆听](#唤醒词聆听)。

### 媒体播放

这组设置决定用语音播放 YouTube 和 YouTube Music 时使用哪个浏览器。改完立即生效，不重启 Gateway。

选择播放器浏览器：

| 选项 | 说明 |
| --- | --- |
| **自动**（默认） | 用第一个已安装的浏览器。macOS 上的顺序是 Google Chrome、Microsoft Edge、Brave、Chromium；Linux 上的顺序是 Chromium、Google Chrome、Brave、Microsoft Edge。 |
| **Google Chrome**、**Microsoft Edge**、**Chromium**、**Brave** | 使用该浏览器。未安装的浏览器标有 **未安装**，不能选择。 |

Gateway 找不到任何支持的浏览器时，面板显示 **没有找到支持的浏览器。请安装 Google Chrome、Microsoft Edge、Brave 或 Chromium。**

播放器使用自己单独的资料目录，即配置目录中的 `player/<browser>/`，不会使用你平时所用浏览器的资料。

- **设置播放器** 在播放器的普通窗口中打开 YouTube。登录一次你的账号，以后播放都使用这个登录。播放器没能打开时，面板显示 **播放器没有打开**。
- **说话时暂停播放** 默认开启。你开口时播放器暂停，助手回答完再继续播放。
- **停止播放后回到助手** 默认关闭。开启后，播放停止时（例如你停止播放或关闭播放器），能显示对话的客户端会把对话窗口调到前面，桌面版就是这样的客户端。

### 电脑控制

决定后台 Agent 能不能看你的屏幕、用你的鼠标和键盘，以及什么时候要先问你：

| 选项 | 行为 |
| --- | --- |
| **Ask once per task**（默认） | 任务第一次需要使用电脑时询问，之后到任务结束都不再询问。 |
| **Ask every time** | 每次截图、点击和按键之前都询问。 |
| **Never ask** | 不询问，直接使用屏幕、鼠标和键盘。只在你信任每个任务时使用。 |
| **Off** | 助手不能看你的屏幕，也不能使用鼠标和键盘。 |

后台 Agent 请求电脑控制时，WebUI 显示 **允许** 和 **拒绝**。**允许** 的范围由上面的设置决定：任务剩余的部分，或者只是这一步。电脑控制没有 **始终允许** 按钮。

### 工作目录

**选择文件夹** 打开与顶部栏相同的目录选择器，点 **用这个文件夹** 保存。详见[工作目录切换](#工作目录切换)。

### 音色

点击音色即可使用。列表包括 Jennifer、Aiden、Ryan、Mione、Tina、Andre、Cindy、Lenn 和 Siiri。新音色立即生效，不重启 Gateway：

- 如果语音会话已打开，当前回答会停止，会话用新音色重新连接，对话内容保留。
- 人设切换为新音色的角色。

点音色旁的 **▶** 可试听一句示例。示例由一个单独的短时语音会话播放，不会进入对话。花费显示会计入试听。

**机械音效** 给回答的音频加上轻微的变调、金属回声和扫频。滤镜由 Gateway 施加，试听也会使用。改完立即生效。

### 断句

| 滑块 | 范围 | 作用 |
| --- | --- | --- |
| **停顿多久算说完** | 0.2 到 6 秒，步长 0.1 秒 | 静音多久后助手认为你说完了。调大一点，中途思考的停顿就不会被当成说完。语音服务最长只支持 6 秒。 |
| **拾音灵敏度** | 0 到 1，步长 0.05 | 调高一点，回声和环境音就不容易打断助手。 |

松开滑块时才保存，每次保存都会重启 Gateway。`config.env` 中没有这两个值时，语音模型使用自己的默认值，滑块显示 0.8 秒和 0.50。

### 隐私

**让语音模型自己联网搜索** 默认关闭。关闭时，查资料都交给后台 Agent，它会读原文、交叉核实。打开后，语音模型可以自己使用 `web_search` 和 `fetch_url` 工具，更快但更浅，搜索词会发给搜索服务商。

**只把一句话摘要发给语音模型** 默认关闭。关闭时，Gateway 会把后台 Agent 的完整回复发给语音服务商，好让它念出来。开启后只转发后台自己写的 `VOICE:` 那一行，超过 900 个字符会被截短。没写这一行时，只发送 `Done. The full result is on screen.`。完整结果仍显示在屏幕上，提醒和权限请求不受影响。

## 唤醒词聆听

只有浏览器版 WebUI 使用唤醒词门控。其他客户端（例如桌面版和 TUI）忽略 **聆听方式** 设置，始终在听，停止短语对它们也不起作用。

### 唤醒过程

在唤醒词模式下，麦克风音频只交给 Gateway 中的唤醒词检测器，不会发给语音模型，服务商也就不会计费。顶部状态显示 **等待唤醒词**，语音球下方提示 **说“Hey Jarvis”唤醒我**（显示所选的唤醒词）。

检测器听到唤醒词后：

1. WebUI 播放唤醒提示音。
2. Gateway 把之前 1.5 秒的音频和之后的全部音频发给语音模型。
3. Gateway 检查第一条转写。转写中没有唤醒词时，Gateway 会在你听到回答之前取消这一轮，把它从对话中删除，然后重新等待唤醒词。
4. 如果只说了唤醒词，助手不回答，继续等你说出请求。

唤醒后如果一直不说话，Gateway 会重新等待唤醒词。等待时间是 6 秒，或 **回答后继续听多久** 的时间加 3 秒，取较长者。

Gateway 第一次等待某个唤醒词时，会从 GitHub 下载该唤醒词的检测器模型到缓存目录。每个文件只下载一次，校验和与固定值一致才会保留。检测器无法启动时，WebUI 显示 `Wake word detection is unavailable`，Gateway 会在 30 秒后重试。

### 回答之后

助手说完后开始后续窗口：WebUI 显示 **还在听，接着说吧** 和一个逐渐缩短的进度条。进度条走完之前说话，不需要唤醒词。窗口结束后，Gateway 重新等待唤醒词。**回答后继续听多久** 设为 0 秒时，回答一结束就等待唤醒词。

Gateway 等待唤醒词期间，助手也可能主动说话，例如播报任务结果或提问。这时你可以直接回答，不需要唤醒词；助手说完后开始同样的后续窗口。

- 窗口从回答的音频播放结束开始计时，而不是从语音模型生成完回答开始。
- 你说话或出现新的回答时，进度条会隐藏，下一次回答结束后重新开始。
- 进度条走完后 Gateway 还会多等 0.5 秒，最后一刻开始说的话不会被截断。
- 语音模型忽略的输入（例如噪音、对别人说的话）不会延长窗口。
- 在唤醒词模式下，关闭麦克风会结束窗口。

### 打断

助手回答时，你可以直接说话打断。你的话会停止当前回答，助手接着回答新的请求，不需要唤醒词。新的回答结束后开始后续窗口。

只说 “stop” 只会打断回答，不会停止聆听。

### 停止短语

说出下面任一短语，助手会重新等待唤醒词：

| 短语 | 聆听方式 |
| --- | --- |
| “stop listening”、“stop listening now”、“go to sleep”、“that's all”、“停止监听”、“别听了” | 两种方式 |
| “never mind”、“nevermind”、“不用了” | 仅 **唤醒词** |

- 这句话里只能有短语本身，前面可以带唤醒词，例如 “Hey Jarvis, stop listening”。
- 助手不回答停止短语，并会取消正在生成的回答。
- 在 **一直在听** 模式下停止短语同样有效：Gateway 转为等待唤醒词，确认唤醒后恢复一直在听。
- 用其他说法要求停止聆听时，语音模型可以调用 `stop_listening` 工具，效果相同。
- 在 **一直在听** 模式下，“never mind” 不会停止聆听。

### 唤醒提示音

唤醒提示音是一段短促的上升双音（E5 到 B5），时长 0.25 秒。每次由唤醒词唤醒时播放一次；打开后续窗口或助手主动说话时不播放。提示音播放期间麦克风继续发送音频，所以说完唤醒词可以直接接着说。停止播放不会切断提示音。

## 与其他客户端的关系

TUI、WebUI、桌面悬浮球都使用同一套 Gateway Client Protocol。一个 Gateway
对每个用户只接受**一个活动 Client 连接**；另一客户端可在确认后接管，旧连接会断开。
桌面版也可以运行自己的 Gateway 进程，并与 CLI 共享用户配置。桌面版的对话窗口
复用同一套 WebUI 页面，因此各端的展示行为保持一致。
顶部控件、设置面板和唤醒词聆听只在浏览器版 WebUI 中提供。

> 把 WebUI 暴露到本机之外会跨越信任边界：请在前面加带认证的 HTTPS 反向
> 代理，并遵循[远程访问安全](../configuration/advanced.zh.md#远程访问安全)。
